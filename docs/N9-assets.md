No raster transformation, recreation or substitute phoenix was used. CSS controls display sizing.

The Colophon phoenix and wordmark identify the application. They are **not character portrait defaults**. `default-character.svg` is an original neutral cloaked fantasy-adventurer silhouette. `default-banner.svg` is an original quiet mountain landscape. These repository-authored vectors contain no scripts, external resources or user data.

Fresh installers copy `colophon.png` unchanged beside the selected user's local startup/waiting components. Existing desktop-component upgrades require separate reviewed installation and rollback; an application archive alone does not replace files in the desktop home. Never store uploaded images in this public static directory.
